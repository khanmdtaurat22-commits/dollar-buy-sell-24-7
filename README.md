# Dollar Buy Sell 24/7 Service

A responsive demo exchange frontend built with React, TypeScript, Vite and Lucide icons.

## Included
- Dark navy, green and gold visual identity
- English/Bangla language toggle
- Eight requested currency/payment options
- Demo exchange calculator with configurable sample pairs
- Demo order creation and tracking in browser memory
- Admin demo controls for rates, fees, reserves, operator status and order statuses
- Responsive desktop/mobile layout

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite.

## Important limitations
This is a frontend demo starter, not a production exchange.
- Rates and reserves are illustrative demo values.
- Orders and settings are stored only in browser memory and reset on refresh.
- Login is a demo placeholder; Supabase Auth is not connected.
- Admin Demo is not protected by real authentication.
- No real deposit, withdrawal, wallet, payment gateway, crypto transfer or settlement exists.
- Do not accept customer funds or publish it as a live financial service.

## Before production
Connect Supabase using server-side functions and strict Row Level Security. Implement real admin authorization, audit logs, persistent database storage, rate limiting, server-side calculations, monitoring, backups and independent security review. Obtain professional legal/regulatory advice and any required approvals before offering real-money or crypto exchange services.
